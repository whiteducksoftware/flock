# Microsoft Foundry Hosting

This directory contains the adapter that hosts a `FlockApplication` as a
Microsoft Foundry hosted agent (Responses protocol). Install it with
`flock-core[foundry]`.

Canonical documentation lives in:

- Docs site guide: https://whiteducksoftware.github.io/flock/guides/foundry/
- Repository example: ../../../../examples/14-foundry/README.md

Use this README as a pointer only to avoid content drift between implementation docs and user-facing docs.
